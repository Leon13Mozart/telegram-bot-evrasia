EVRASIA MASTERCLASS — FIREBASE + BOT API

1. Replace the server bot file with bot_firebase_api.py (or run it as a test copy).
2. Install requirements:
   pip install -r requirements_site.txt
3. Set environment variables:
   BOT_TOKEN=...
   DATABASE_PATH=telegram_stats.db
   WEB_APP_URL=https://evrasia-masterclass.web.app
   WEB_ALLOWED_ORIGINS=https://evrasia-masterclass.web.app,https://evrasia-masterclass.firebaseapp.com
   PORT=8000
4. Start:
   python bot_firebase_api.py
5. Test locally/on server:
   curl http://127.0.0.1:8000/api/health
   Expected: {"ok":true,"service":"evrasia-masterclass-api"}
6. The API must be exposed through HTTPS before Firebase can call it.
7. Put that HTTPS URL in web/config.js:
   window.MK_API_BASE = "https://YOUR-API-HTTPS-URL";
8. Redeploy Firebase:
   firebase deploy --only hosting

Google Sheets sync is NOT removed. Registrations continue to be stored in SQLite and synced to Google during testing.
